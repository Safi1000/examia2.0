The statement of financial position for IGCSE 0452 and O Level 7707 lists what a business owns and owes on one date. Assets come first: non-current assets at cost less accumulated depreciation, then current assets. Below them sit capital (opening capital, plus profit, less drawings) and liabilities, non-current then current. Total assets must equal capital plus liabilities.

## What is the statement of financial position format?

Here is the full layout for a sole trader. X is a figure and (X) is a figure being deducted. Items go in the inner columns and subtotals in the outer column.

**[Business name]: Statement of financial position at [date]**

| | Cost $ | Accumulated depreciation $ | Net book value $ |
|---|---:|---:|---:|
| **Non-current assets** | | | |
| Premises | X | X | X |
| Fixtures and fittings | X | X | X |
| Motor vehicles | X | X | X |
| | X | X | X |
| **Current assets** | | | |
| Inventory | | | X |
| Trade receivables | | X | |
| Less allowance for irrecoverable debts | | (X) | X |
| Other receivables | | | X |
| Bank | | | X |
| Cash | | | X |
| | | | X |
| **Total assets** | | | **X** |
| **Capital and liabilities** | | | |
| Capital at start of year | | | X |
| Add profit for the year | | | X |
| | | | X |
| Less drawings | | | (X) |
| | | | X |
| **Non-current liabilities** | | | |
| Bank loan | | | X |
| **Current liabilities** | | | |
| Trade payables | | X | |
| Other payables | | X | |
| Bank overdraft | | X | X |
| **Total capital and liabilities** | | | **X** |

Four rules sit behind this layout:

- **The heading has three parts**: the business name, the name of the statement, and "at" the date. It shows one moment, so it is never "for the year ended". Mark schemes use both "at" and "as at".
- **Every section gets a heading and a total.** Non-current assets, current assets, capital, non-current liabilities, current liabilities.
- **The two totals must match.** Total assets equals total capital and liabilities. That is the accounting equation (assets = capital + liabilities) set out as a statement.
- **Each item appears once.** A bank balance is either a current asset (money in the bank) or a current liability (an overdraft), never both.

The statement of financial position is the second statement you prepare from a trial balance. The first is the statement of profit or loss, covered line by line in my [income statement format guide](/blog/igcse-o-level-accounting-income-statement-format). Its last figure, profit for the year, is what links the two.

## What names does Cambridge use from 2027?

The statement keeps its name. The 2027 to 2029 syllabuses for 0452 and 7707 both say statement of financial position, as past papers have for years. Most names inside it were also in use before 2027. This table matches them to the names in older textbooks and mark schemes.

| Name you may still see | Name in the 2027 syllabus |
|---|---|
| Balance sheet | Statement of financial position |
| Fixed assets | Non-current assets |
| Provision for depreciation | Accumulated depreciation |
| Provision for doubtful debts | Allowance for irrecoverable debts |
| Debtors | Trade receivables |
| Creditors | Trade payables |
| Stock | Inventory |
| Accrued expenses, income received in advance | Other payables |
| Prepaid expenses, income accrued | Other receivables |
| Long-term liabilities | Non-current liabilities |

"Balance sheet", "fixed assets", "debtors", "creditors" and "stock" are textbook names. Mark schemes up to 2026 still said provision for depreciation and provision for doubtful debts. The 2027 syllabus says allowance for irrecoverable debts (topic 4.4). For depreciation it uses both names: a provision for depreciation account in the ledger (topic 4.2) and accumulated depreciation on the statement (topic 5.1).

The October/November 2024 0452 mark scheme accepted "long-term liabilities" alongside non-current liabilities. Use the newest names, and recognise the old ones when a question uses them.

## What goes in each section?

Topic 5.1 of the 2027 syllabus lists the content: non-current assets, intangible assets, current assets, current liabilities, non-current liabilities and capital. Here is what each one means and in what order things go.

### Non-current assets

Non-current assets are resources the business keeps and uses for more than a year: premises, machinery, fixtures and fittings, motor vehicles. Each is shown in three columns: **cost**, **accumulated depreciation** (all depreciation charged since the asset was bought) and **net book value** (cost less accumulated depreciation).

Accumulated depreciation is the balance from the trial balance **plus** this year's charge. Students often deduct only the trial balance figure. Land and premises are often not depreciated, so the middle column shows a nil figure for them.

Non-current assets are shown at net book value, not at what they could be sold for. The November 2023 7707 examiner report makes this point, after a good number of candidates chose the answer that depreciation shows an asset at market value.

Intangible assets are non-current assets with no physical form. The syllabus names them as part of the content, so if a question gives one, show it with the non-current assets under its own label.

### Current assets

Current assets are short-term: cash, or items expected to turn into cash within a year. Cambridge mark schemes list them from least liquid to most liquid. Inventory comes first, and bank and cash come last:

1. **Inventory**: closing inventory from the notes, not the trial balance figure.
2. **Trade receivables**, less the allowance for irrecoverable debts, giving net trade receivables.
3. **Other receivables**: prepaid expenses and income still to be received.
4. **Bank**, if the account is in credit (money in the bank).
5. **Cash** in hand.

### Capital

Capital is what the business owes the owner. Show the working, never one figure:

- Capital at the start of the year (the trial balance figure)
- Add profit for the year (or deduct a loss)
- Add any capital introduced during the year
- Less drawings (cash, plus any goods or private bills taken by the owner)

The answer is closing capital. Drawings are never an expense and never a liability. They reduce capital.

### Non-current liabilities

These are debts not due for repayment within a year, such as a long-term bank loan. If the trial balance says "bank loan (repayable 2031)", it is non-current. The loan interest is an expense in the income statement. It is not added to the loan.

### Current liabilities

These are debts due within a year. Mark schemes list them in this order:

1. **Trade payables**: money owed to suppliers for goods.
2. **Other payables**: expenses owing and income received in advance.
3. **Bank overdraft**: money owed to the bank on the current account.

## How do year-end adjustments change the statement of financial position?

Every adjustment has two sides. One lands in the income statement. The other lands here, as an asset or liability that did not exist in the trial balance, or as a changed figure.

| Adjustment | Where it goes on the statement of financial position |
|---|---|
| Expense owing (accrued) | Other payables, a current liability |
| Expense paid in advance (prepaid) | Other receivables, a current asset |
| Income still to be received | Other receivables, a current asset |
| Income received in advance | Other payables, a current liability |
| Depreciation for the year | Added to accumulated depreciation, lowering net book value |
| Irrecoverable debt written off | Deducted from trade receivables |
| Allowance for irrecoverable debts | Closing balance deducted from trade receivables |
| Closing inventory | First current asset |
| Bank charges or interest not yet recorded | Added to the overdraft, or deducted from the bank balance |
| Goods or private bills taken by owner | Added to drawings |

### Accruals and prepayments

A prepayment is an asset because the business has paid for something it has not yet used. If $600 of insurance covers next year, that $600 is an other receivable. An accrual is a liability: if $1 200 of wages is owing, that $1 200 is an other payable. You can show other receivables and other payables as one total with a working, or item by item with clear labels. Mark schemes accept either.

### Irrecoverable debts and the allowance

This adjustment appears in examiner reports year after year. The order matters:

1. Write off the irrecoverable debt from trade receivables first.
2. Work out the new allowance on the remaining balance.
3. Show trade receivables less the **full closing allowance**, with the net figure in the outer column.

The income statement takes only the change in the allowance. The statement of financial position takes the whole closing balance. The allowance is never a liability and never a separate line in current assets.

### Inventory

Closing inventory appears twice: deducted in cost of sales and listed as a current asset. Topic 4.5 also asks for the effect of a wrong valuation. If closing inventory is overvalued, current assets are too high, and so is profit for the year. That makes closing capital too high by the same amount, so the statement still balances. A balancing statement can still be wrong.

### Bank overdraft

An overdraft is a credit balance on the bank account, so it is a current liability. The November 2022 0452 report notes that a credit balance in a trial balance can only be income or a liability, yet candidates still treated an overdraft as an asset. If the notes give bank charges not yet recorded, add them to the overdraft. The March 2025 0452 report says most candidates "did not adjust the bank overdraft for the bank charges".

<Tip title="Use the trial balance side">
Before you place an item, look at which column it sits in. Debit balances are assets, expenses or drawings. Credit balances are income, liabilities or capital. Accumulated depreciation and the allowance are credits, but they are deductions from assets, not liabilities.
</Tip>

This is where most students get stuck: one adjustment changes two statements, and it is easy to do one side and forget the other. The worked example below shows how I tick off both sides.

## How do you prepare a statement of financial position from a trial balance?

Ayesha owns a hardware shop. Here is her full trial balance.

**Ayesha: Trial balance at 31 December 2026**

| Account | Dr $ | Cr $ |
|---|---:|---:|
| Premises at cost | 80 000 | |
| Fixtures and fittings at cost | 24 000 | |
| Accumulated depreciation of fixtures and fittings | | 7 200 |
| Motor vehicle at cost | 30 000 | |
| Accumulated depreciation of motor vehicle | | 12 000 |
| Inventory at 1 January 2026 | 15 000 | |
| Revenue | | 190 000 |
| Sales returns | 2 000 | |
| Purchases | 96 000 | |
| Purchases returns | | 1 500 |
| Commission received | | 2 400 |
| Wages | 28 000 | |
| Rates and insurance | 4 800 | |
| Electricity | 3 000 | |
| General expenses | 6 200 | |
| Loan interest | 900 | |
| Irrecoverable debts | 400 | |
| Trade receivables | 21 000 | |
| Allowance for irrecoverable debts at 1 January 2026 | | 600 |
| Trade payables | | 13 800 |
| Cash in hand | 500 | |
| Bank overdraft | | 3 600 |
| Bank loan (repayable 2031) | | 15 000 |
| Capital at 1 January 2026 | | 83 700 |
| Drawings | 18 000 | |
| **Totals** | **329 800** | **329 800** |

### The notes at 31 December 2026

1. Inventory was valued at $17 400.
2. Wages of $1 200 and electricity of $250 were owing.
3. Insurance of $600 was paid in advance.
4. Commission of $300 was due to Ayesha but not yet received.
5. The bank statement shows bank charges of $150 not yet entered in the books.
6. Depreciation: fixtures and fittings at 10% a year on cost, motor vehicle at 25% a year by the reducing balance method. Premises are not depreciated.
7. A debt of $1 000 is to be written off. The allowance is to be 5% of the remaining trade receivables.
8. Ayesha took goods costing $800 for her own use. No entry has been made.

After all these adjustments, Ayesha's profit for the year is $46 800. Here is where it comes from, in short. The full method is in the income statement guide linked above.

| | $ |
|---|---:|
| Revenue (190 000 less 2 000) | 188 000 |
| Less cost of sales (15 000 + 96 000 less 1 500 less 800 less 17 400) | (91 300) |
| Gross profit | 96 700 |
| Add commission received (2 400 + 300) | 2 700 |
| Less expenses | (52 600) |
| **Profit for the year** | **46 800** |

The expenses are wages 29 200, rates and insurance 4 200, electricity 3 250, general expenses 6 200, loan interest 900, bank charges 150, irrecoverable debts 1 400, the increase in the allowance 400 and depreciation 6 900.

### Workings

| Item | Working | $ |
|---|---|---:|
| Accumulated depreciation: fixtures | 7 200 + (24 000 × 10%) 2 400 | 9 600 |
| Accumulated depreciation: vehicle | 12 000 + ((30 000 less 12 000) × 25%) 4 500 | 16 500 |
| Trade receivables | 21 000 less 1 000 | 20 000 |
| Allowance | 20 000 × 5% | 1 000 |
| Other receivables | insurance 600 + commission 300 | 900 |
| Other payables | wages 1 200 + electricity 250 | 1 450 |
| Bank overdraft | 3 600 + 150 | 3 750 |
| Drawings | 18 000 + 800 | 18 800 |

Two things to notice. The vehicle's charge uses net book value ($18 000), not cost. And the allowance goes in at its full $1 000, not the $400 increase that went to the income statement.

### The finished statement

**Ayesha: Statement of financial position at 31 December 2026**

| | Cost $ | Accumulated depreciation $ | Net book value $ |
|---|---:|---:|---:|
| **Non-current assets** | | | |
| Premises | 80 000 | 0 | 80 000 |
| Fixtures and fittings | 24 000 | 9 600 | 14 400 |
| Motor vehicle | 30 000 | 16 500 | 13 500 |
| | 134 000 | 26 100 | 107 900 |
| **Current assets** | | | |
| Inventory | | | 17 400 |
| Trade receivables | | 20 000 | |
| Less allowance for irrecoverable debts | | (1 000) | 19 000 |
| Other receivables | | | 900 |
| Cash | | | 500 |
| | | | 37 800 |
| **Total assets** | | | **145 700** |
| **Capital and liabilities** | | | |
| Capital at 1 January 2026 | | | 83 700 |
| Add profit for the year | | | 46 800 |
| | | | 130 500 |
| Less drawings | | | (18 800) |
| | | | 111 700 |
| **Non-current liabilities** | | | |
| Bank loan (repayable 2031) | | | 15 000 |
| **Current liabilities** | | | |
| Trade payables | | 13 800 | |
| Other payables | | 1 450 | |
| Bank overdraft | | 3 750 | 19 000 |
| **Total capital and liabilities** | | | **145 700** |

Check the arithmetic: 107 900 + 37 800 = 145 700. On the other side, 111 700 + 15 000 + 19 000 = 145 700. It balances.

Notice what is missing. There is no "Bank" line under current assets, because Ayesha's bank account is overdrawn. Loan interest, wages and the other expenses are not here at all: they went to the income statement. And the opening inventory of $15 000 appears nowhere, because it was used up in cost of sales.

## How is the statement of financial position marked?

Paper 2 for both 0452 and 7707 is 1 hour 45 minutes, with five compulsory questions of 20 marks each, worth 70% of the qualification. A full statement of financial position is one part of a question, not a whole question. Some papers ask only for an extract, such as current assets or current liabilities.

The February/March 2024 0452 Paper 22 mark scheme (Question 4(c)) gave 7 marks for a sole trader's full statement. Looking at it, the marks fell like this:

- one for the non-current assets total (cost, accumulated depreciation and net book value)
- one for net trade receivables after the allowance
- one "own figure" mark for the current assets total
- one for closing capital
- one for the loan as a non-current liability
- one for other payables
- one "own figure" mark for the current liabilities total

Inventory, cash and trade payables, copied straight from the question, earned no mark of their own. The marks go to the figures you had to adjust and to the section totals. An extract question works the same way. The February/March 2025 mark scheme gave 4 marks for current liabilities. There was one each for the adjusted other payables, the income received in advance, the overdraft after bank charges, and the total.

**Own figure** marks matter. If your net trade receivables figure is wrong but you add the current assets correctly, you can still earn the total mark. The examiner follows your figures. So always total every section, even when you are unsure of a line above.

The statement also feeds later parts. In March 2026 the next part asked for the liquid (acid test) ratio from the candidate's own current assets and current liabilities. Working capital and the current ratio use the same two totals. My [accounting ratios guide](/blog/igcse-o-level-accounting-ratios-formulas) has every formula, and you can check your answers with the [ratio calculator](/tools/ratio-calculator).

## Where do candidates lose marks?

These come from Cambridge examiner reports for 0452 and 7707 between 2022 and 2026. Each row says what kind of question the report was about. Most were limited company statements, but the assets and liabilities sections are laid out the same way for a sole trader.

| Error | Reported in |
|---|---|
| No column headings for cost, depreciation and net book value | 0452 and 7707 June 2023 (limited company) |
| Section headings or section totals missing | 0452 and 7707 June 2023, 0452 June 2025 (limited company); 0452 and 7707 June 2022 (club extract, no total) |
| Assets and liabilities not split into non-current and current | 0452 March 2026 (limited company) |
| Allowance shown as a liability, added to current assets, or taken off total current assets | 0452 and 7707 June 2023, 0452 June 2025, March 2026 (all limited company) |
| Bank overdraft shown as an asset or as a non-current liability | 0452 November 2022 (sole trader); 0452 June 2025 (limited company) |
| Overdraft not adjusted for bank charges; accruals or income received in advance left out or badly labelled | 0452 March 2025 (sole trader extract) |
| Extra items included, such as debenture interest or profit for the year in a company statement, or provision for depreciation listed as a liability | 0452 and 7707 June 2023, 0452 June 2025, March 2026 (all limited company) |
| Profit for the year or goods taken by the owner left out of the capital account | 0452 and 7707 June 2022, 0452 March 2026 (sole trader capital accounts) |

The same reports carry good news. In June 2023 the company statement was answered well by many candidates on both syllabuses. The March 2026 report describes what the stronger company answers had: a sound format, every item in the right section, headings at the side and subtotals. That is the layout on this page.

<Tip title="Headings first, figures second">
Write the full skeleton before any numbers: the heading, the three column titles, and the five section headings. Then fill in. Missing headings and totals appear in report after report, and they are the cheapest marks on the page.
</Tip>

## How do partnership and limited company statements differ?

The assets and liabilities sections are the same. Only the capital section changes. In topic 5.2, partners' capital and current accounts are shown as part of the statement of financial position. In topic 5.3, companies show equity: share capital, general reserve and retained earnings.

| Business | Capital section |
|---|---|
| Sole trader | Opening capital, add profit, less drawings |
| Partnership | Each partner's capital account balance, then each partner's current account balance |
| Limited company | Equity: ordinary share capital, preference share capital, general reserve, retained earnings |

For a company, debentures are a non-current liability, and the debenture interest goes in the statement of profit or loss, not here. Partnerships are covered in my [partnership accounts guide](/blog/igcse-accounting-partnership-accounts).

|---|---|

### Question 2: current assets, current liabilities and working capital

Omar's balances at 30 June 2027: inventory $9 200, trade receivables $14 000, cash $400, trade payables $7 500, bank overdraft $2 100.

Notes: a debt of $400 is to be written off; the allowance is to be 2.5% of the remaining trade receivables; rent of $300 is prepaid; electricity of $180 is owing; rent of $250 has been received in advance from a tenant; bank charges of $60 have not been recorded.

Prepare the current assets and current liabilities sections, then calculate working capital.

**Answer**

| | $ | $ |
|---|---:|---:|
| **Current assets** | | |
| Inventory | | 9 200 |
| Trade receivables (14 000 less 400) | 13 600 | |
| Less allowance for irrecoverable debts | (340) | 13 260 |
| Other receivables | | 300 |
| Cash | | 400 |
| | | 23 160 |
| **Current liabilities** | | |
| Trade payables | 7 500 | |
| Other payables (180 + 250) | 430 | |
| Bank overdraft (2 100 + 60) | 2 160 | 10 090 |

Working capital is current assets less current liabilities: 23 160 less 10 090 = $13 070. The allowance is 13 600 × 2.5% = $340, worked out after the write-off.

### Question 3: the capital section

Farah's capital at 1 April 2026 was $52 000. During the year she paid in a further $5 000 of her own money. She made a loss for the year of $3 500. She withdrew $9 000 in cash and took goods costing $600.

Prepare the capital section at 31 March 2027.

**Answer**

| | $ |
|---|---:|
| Capital at 1 April 2026 | 52 000 |
| Add capital introduced | 5 000 |
| | 57 000 |
| Less loss for the year | (3 500) |
| | 53 500 |
| Less drawings (9 000 + 600) | (9 600) |
| **Capital at 31 March 2027** | **43 900** |

A loss is deducted where a profit would be added. The goods taken are drawings, just like the cash.

## FAQ

### What is the format of a statement of financial position in O Level Accounting?

A three-part heading with "at" the date. Then non-current assets, current assets and total assets. Then capital, non-current liabilities, current liabilities and a total that equals total assets. The same format is used for IGCSE 0452.

### Is a balance sheet the same as a statement of financial position?

Yes. Balance sheet is the older name still used in some textbooks. Cambridge papers and both 2027 syllabuses say statement of financial position.

### Is a bank overdraft a current asset or a current liability?

A current liability. It is money the business owes the bank, usually repayable on demand. Show it last under current liabilities, after any bank charges are added.

### Where does the allowance for irrecoverable debts go?

Deduct the full closing allowance from trade receivables in current assets, and show the net figure. It is never a liability. Only the change in the allowance goes to the income statement.

### Does profit for the year go on the statement of financial position?

For a sole trader, yes: it is added to opening capital in the capital section. A loss is deducted in the same place. It is never listed as an asset or a liability.

The statement of financial position is in topic 5.1 Sole traders, with the adjustments in topic 4. You can tick off each point on the [0452 syllabus checklist](/syllabus/igcse-accounting-0452#s-5.1).
