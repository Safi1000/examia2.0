# How to add an article

1. Copy `igcse-accounting-trial-balance.mdx` and rename it. The file name becomes the web address: `my-new-topic.mdx` → hamzateaches.com/blog/my-new-topic. Use lowercase and dashes.
2. Edit the `meta` block at the top: title, description (about 155 characters), subject (Accounting, Business or Economics), level (O Level / IGCSE, AS Level or A2 Level), code, type (Topic, Exam technique or Past paper) and date (yyyy-mm-dd).
3. Write in plain Markdown: `##` for headings, `-` for bullets, `**bold**`, tables with `|`.
4. Put `<BookingBox />` on its own line after the first main section. The end-of-article booking box is added automatically.
5. Optional: `<Tip>…</Tip>` for an exam tip box.
6. Files starting with `_` are drafts and are not published.

Past papers: quote question numbers and short extracts only, and link to the official paper. Never paste a full paper or mark scheme.
